This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a learning project for the DataTalksClub Data Engineering Zoomcamp, covering Docker, Postgres, and Terraform. It's a small, evolving sandbox rather than a production codebase — expect scripts and structure to change as new modules are worked through.

## Environment

- Python >=3.13, managed with `uv` (see `pyproject.toml` / `uv.lock`).
- Install dependencies: `uv sync`
- Run a script: `uv run python <script.py>`

## Commands

- Build the pipeline Docker image (run from `de_bootcamp_docker_terraform/`):
  ```
  docker build -t taxi_ingest:v001 .
  ```
- Run the pipeline container, passing the month argument:
  ```
  docker run -it taxi_ingest:v001 <month>
  ```

## Architecture

- `pipeline/pipeline.py` — the containerized ETL entrypoint. Takes a month as a CLI argument (`sys.argv[1]`) and will grow into the NY taxi data ingestion pipeline.
- `Dockerfile` — builds the pipeline image on `python:3.13.11-slim`, installs `pandas`/`pyarrow`, copies `pipeline/pipeline.py` in, and sets it as the container's entrypoint. Build from the repo root (`de_bootcamp_docker_terraform/`) so the `pipeline/` path resolves.
- `ny_taxi_postgres_data/` — Postgres data directory, intended to be mounted as a volume for a Postgres container holding NY taxi trip data. Gitignored — it's regenerated by the container, not source.
- `data/` — local data directory (currently empty), for pipeline input/output. Gitignored.
